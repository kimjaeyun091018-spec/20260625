# ABYSS — 심연 (Python 버전)

HTML/브라우저판 `abyss_topdown.html`을 **pygame**으로 이식한 데스크톱 실행 버전입니다.
브라우저 호환성 문제(이미지 디코딩, Web Audio 자동재생 정책, 키보드 캡처 등) 때문에
생길 수 있는 "특정 동작이 안 되는" 문제를 피하려고, 파이썬 + pygame으로 완전히
새로 작성했습니다. 외부 음원 파일은 전혀 쓰지 않고, 모든 효과음은 numpy로
절차적으로 합성합니다.

## 실행 방법

1. 파이썬 3.9 이상이 필요합니다.
2. 이 폴더에서 의존 라이브러리를 설치합니다.

   ```bash
   pip install -r requirements.txt
   ```

   (또는 `pip install pygame numpy`)

3. 실행합니다.

   ```bash
   python3 abyss_topdown.py
   ```

## 조작법

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space (누르고 있기) | 달리기 |
| E | 조사 (사물함/캐비닛/패널) · 잠긴 문에 열쇠 사용 · 계단 오르내리기 |
| Esc | 종료 |

창 크기는 자유롭게 조절할 수 있습니다(Resizable).

## 폴더 구성

```
abyss_python/
├── abyss_topdown.py   ← 실행할 파일 (렌더링/입력/오디오 재생)
├── game_logic.py       ← 순수 로직 (맵, 충돌, 시야 차단, 문 상태 머신, 침수 계산)
├── sound_synth.py       ← 효과음 절차적 합성 (numpy)
├── assets/
│   ├── sprite.png       ← 캐릭터 스프라이트시트(제공해주신 .piskel에서 추출한 PNG)
│   └── font_kr.ttf       ← 한글 렌더링용 서브셋 폰트 (Noto Sans Mono CJK KR 일부)
├── requirements.txt
└── README.md (이 파일)
```

`game_logic.py`와 `sound_synth.py`는 pygame에 의존하지 않는 순수 파이썬/numpy
코드라서, 맵 레이아웃이나 문/침수 동작 같은 핵심 규칙이 원작 HTML 버전과 똑같이
맞물리는지 pygame 없이도 유닛 테스트할 수 있습니다(이번 작업 중 36개 로직
테스트 + 사운드 합성 테스트를 전부 통과시킨 뒤 포함했습니다).

## HTML 버전과 달라진 점 / 구현 메모

- **사운드**: Web Audio API 대신 numpy로 파형을 미리 합성해 `pygame.mixer`로
  재생합니다. 발소리·문 소리처럼 자주 나는 소리는 몇 가지 변형을 미리 만들어
  두고 매번 무작위로 골라 재생해, 실시간 합성 없이도 단조롭지 않게 했습니다.
- **스프라이트**: 제공해주신 `.piskel` 캐릭터는 거의 검은색이라 어두운 바닥과
  구분이 잘 안 되는 문제가 있었습니다(HTML판에서도 같은 문제로 고생했던
  부분입니다). 여기서는 불러온 즉시 명도 기반으로 청록색 다이빙수트 톤으로
  재채색하고, 혹시 스프라이트 로드에 문제가 생기더라도 캐릭터가 항상 보이도록
  이미지 없이 그리는 벡터 마커(캡슐 모양 + 눈)를 바탕에 깔고 그 위에
  스프라이트를 덧그립니다.
- **오디오 장치가 없는 환경**: 일부 서버/가상환경처럼 오디오 장치가 없는
  곳에서 실행해도 게임 자체는 멈추지 않고 무음으로 계속 진행되도록
  예외 처리를 해뒀습니다.
- **한글 폰트**: 시스템에 한글 폰트가 없어도 항상 똑같이 보이도록, 이 폴더
  안에 작은 한글 서브셋 폰트를 동봉했습니다(게임에서 쓰는 글자만 추려서
  약 95KB로 줄였습니다).

## 문제 해결

- **소리가 하나도 안 들려요**: 콘솔에 `[경고] 오디오 장치를 초기화하지
  못했습니다`가 보이면 시스템에 사용 가능한 오디오 출력 장치가 없는
  것입니다. 게임 진행에는 지장이 없습니다.
- **한글이 네모(□)로 보여요**: `assets/font_kr.ttf` 파일이 실행 파일과
  같은 폴더에 있는지 확인해주세요(폴더째로 옮겨야 합니다, `.py` 파일만
  옮기면 안 됩니다).
- **창이 너무 느려요/버벅여요**: 노트북 내장 그래픽이라면 창 크기를
  줄여보세요(렌더링 범위가 줄어듭니다).

## 다층 구조와 계단 (개발 중인 새 시나리오)

여객선과 화물선이 십자 모양으로 충돌해 결합된 선체를 4개 층(1층 / B1 / B2 / B3)으로 구성했습니다.
시작 위치는 B2 객실 14호입니다.

- 계단통 4개, 층 사이 연결은 세 가지 상태입니다.
  - **정상**: `E`로 오르내림
  - **막힘**: 찌그러진 잔해(통과 불가). 우회로를 찾아야 함
  - **붕괴**: 한 번 지나가면 뒤에서 무너져 되돌아갈 수 없음 (`S2` B2→B3)
- 목표: 제어실(B3)에서 비상 전원을 복구한 뒤 1층 선수의 비상 부이 발사실로 이동.
- 잠긴 문 3개, 열쇠 4개(1개는 여유). 열쇠를 어떤 순서로 써도 막히지 않도록 `tests/test_floors.py`가 검증합니다.

### 시야 (아오오니 방식) 와 창문

- 들어간 방(또는 복도) 하나만 통째로 보입니다. 문은 열려 있어도 시선을 막으므로 옆방/복도는 보이지 않습니다.
- 문 타일 위에 서 있는 순간에는 문 양쪽이 모두 보입니다.
- 창문(`WINDOW`)은 통행은 막지만 시선은 통과시킵니다. 조리실↔식당 배식창, 제어실·격리실·실험체 보관실 관찰창 등이 있고,
  창문을 통해서는 플레이어 위치와 창문 각도에 따라 정해진 범위만 어둡게 보입니다.
- 문짝은 타일 전체 폭으로 그려지고 벽 쪽으로 미끄러지며 열립니다. 충돌 판정도 문짝이 실제로 가리는 영역만 막으므로,
  화면에 보이는 열린 틈이 곧 지나갈 수 있는 틈입니다. 걷거나 달려서 다가가도 멈추지 않도록 2칸 앞에서부터 열립니다.

테스트(pygame 없이 실행 가능):

```bash
python3 tests/test_floors.py
python3 tests/test_vision.py
```
