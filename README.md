# 던전 슈터 (가제)

Soul Knight 스타일의 탑다운 로그라이크 슈팅 게임입니다. **PC 키보드와 마우스**로 플레이하고, **최대 4명 협동 멀티플레이**를 지원합니다.
설치 없이 브라우저에서 바로 실행되므로 태블릿에서도 개발하고 테스트할 수 있습니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 |
| 조준 | 마우스 |
| 공격 | 왼쪽 클릭 (누르고 있으면 연사) · 오토에임을 켜면 Enter |
| 무기 스킬 | 오른쪽 클릭 또는 V |
| 궁극기 | Q |
| 액티브 스킬 (스킬 트리) | 1 / 2 / 3 (로비에서도 시험 가능) |
| 무기 교체 (쿨타임 1.5초) | Tab / 마우스 휠 |
| 상자 열기 · 상점에서 사기 · 무기 줍기 · 로비에서 캐릭터·병영·길드 회관 | E |
| 스킬 트리 열기 (로비) | 제단 앞에서 E, 또는 K |
| 대시 (잠깐 무적) | Space / Shift |
| 울타리 짓기 (베이스캠프, 마우스 위치) | E |
| 터렛 짓기 (마우스 위치) | R |
| 건물 철거 (반값 환불) | F |
| 증강 카드 선택 | 카드 클릭 또는 Z / X / C |
| 스테이지 보상 선택 | 1 / 2 / 3 또는 카드 클릭 |
| 바로 시작 (성 지키기 준비 시간 건너뛰기, 모두 누르면) | G |
| 군단 소환 (성 지키기) | 4 / 5 / 6 / 7 |
| 성 강화 (성 지키기) | T |
| 일시정지 (계속하기 / 메뉴로 나가기) | Esc |

**마우스 없이 하기:** 메뉴나 일시정지의 **⚙ 설정**에서 **오토에임**을 켜세요.
- Enter를 누르고 있으면 가장 가까운 적을 자동으로 조준해서 공격합니다.
- 스킬도 가까운 적을 노립니다.
- 무기 스킬은 V, 증강 카드는 Z/X/C로 고릅니다.

태블릿에서 키보드 없이 테스트할 때는 화면을 터치하거나 펜으로 누르면 그 방향으로 조준하고 사격합니다. 강화 카드도 터치로 고를 수 있지만, 이동은 키보드가 있어야 합니다.

## 게임 흐름

**타이틀 → 시작 메뉴(혼자 / 방 만들기 / 참가) → 로비 → (모험 / 베이스캠프) → 로비**

### 로비 (Soul Knight처럼 걸어 다니는 방)
- **캐릭터 동상 (왼쪽):** 가까이 가면 능력치와 패시브가 보이고, E를 누르면 그 캐릭터가 됩니다. **기사로 시작**하고, 다른 캐릭터는 **정수로 사야** 합니다. 아직 안 산 동상은 흐리게 🔒 가격이 보이며 E를 누르면 캐릭터 상점이 열립니다.
  - 가격: 레인저 ◆4000 · 도적 ◆5000 · 광전사 ◆6000 · 마법사 ◆7500 · 연금술사 ◆9000 (나중에 업적 등으로 정수 얻는 방법을 늘릴 예정)
  - 같은 캐릭터를 여러 명이 골라도 됩니다.
- **스킬 트리 제단 (위):** E 또는 K로 엽니다. **옷장:** 스킨.
- **포털 (오른쪽):** 보라색은 모험, 주황색은 베이스캠프입니다. **모두가 같은 포털에 들어가면** 그 모드로 출발합니다.
- **병영 (왼쪽 아래):** 군단 편성. **길드 회관 (오른쪽 아래):** 온라인 길드.
- **토템 자리 (아래):** 자리만 만들어 두었습니다 (추가 예정).
- 로비에서는 마나가 무한이고, 공격·무기 스킬·액티브 스킬(1~3)을 시험해 볼 수 있습니다.

### 캐릭터
모든 캐릭터는 **권총**을 들고 시작합니다. 체력·마나와 기본 패시브가 다릅니다.

| 캐릭터 | 체력 | 마나 | 패시브 |
|---|---|---|---|
| 기사 | 7 | 90 | 방패: 4초마다 적 탄환 1발을 막음 |
| 레인저 | 5 | 110 | 날렵함: 이동 속도 +15%, 대시 쿨타임 -30% |
| 마법사 | 4 | 170 | 마력 증폭: 장착 스킬 피해 +40%, 마나 구슬 +50% |
| 광전사 | 9 | 60 | 분노: 잃은 체력 1칸마다 피해 +8% |
| 도적 | 5 | 90 | 급소 찌르기: 치명타율 +15%, 치명타 피해 +50% |
| 연금술사 | 6 | 120 | 촉매: 원소 반응 피해 +60%, 반응을 일으키면 마나 +3 |

수치는 `src/data.js`의 `CHARACTERS`에서 바꿀 수 있습니다.

### 스킬 트리와 빌드 (영구 저장) — 거미줄 트리
- 가운데 시작점에서 **일반 스탯 6개**, **속성 가지 6개**(불·물·전기·얼음·바람·독), 그 사이로 **바깥 가지 6개**(성·전투·군단·마나·보물·생존)가 뻗어 나가고, 서로 가로로도 이어진 **거미줄** 모양입니다.
  - 속성 가지 순서: 각인 → 액티브 스킬 1 → 패시브 특성 → 숙련 → 액티브 스킬 2
  - 바깥 가지: 스탯 3개 → 끝에 **왕관 노드**
- **해금 규칙:** 이어진 노드 중 **하나만** 해금돼 있으면 열 수 있습니다 (여러 길로 돌아갈 수 있음). 한 번 해금하면 영구입니다.
- **재화 두 가지**
  - **정수(◆):** 적 처치, 방·스테이지 클리어, 보스 처치로 얻습니다. 모든 플레이어가 똑같이 받습니다.
  - **왕관(♛):** 모험 모드 보스 처치 +1, 성 지키기 승리 +2. 왕관 노드에 씁니다.
  - 둘 다 판이 끝나거나 중간에 나갈 때 저장됩니다.
- **조작:** 빈 곳을 끌어서 이동, 마우스 휠이나 ＋/－ 버튼으로 확대, ⟲로 처음 위치.
- **속성 각인을 해금하면 그 속성이 바로 캐릭터 속성이 됩니다** (캐릭터 발밑 고리 색). 스킬을 해금하면 빈 장착 칸에 바로 들어갑니다.
- **빌드 칸 (최대 4개):** 빌드마다 캐릭터 속성 1개와 **액티브 3칸**(1·2·3 키로 사용) + **패시브 2칸**(항상 켜짐)을 정합니다.
- **빌드 저장(잠금):** 지금 고른 빌드 칸은 저장하지 않아도 그대로 게임에 적용됩니다. 저장하면 잠겨서 실수로 바뀌지 않고, 고치려면 초기화(◆25)가 필요합니다.
  - 빌드 칸 추가 구매: ◆120 / ◆240 / ◆400
- **일반 스탯·바깥 가지·왕관 노드**는 해금하면 항상 적용되고, **숙련**은 캐릭터 속성이 같을 때만 속성 레벨 +1입니다.
- 저장은 **이 브라우저**에 됩니다. **구글로 로그인**하면 서버에도 저장돼서 다른 기기에서 이어 할 수 있어요 (아니면 저장 코드로 옮기기).

| 바깥 가지 | 스탯 노드 (◆) | 왕관 노드 (♛) |
|---|---|---|
| 성 | 성 체력 +10, 성 화살 +50%, 시작 골드 +20 | 난공불락: 성 체력 +50% (♛2) |
| 전투 | 치명 +5%, 피해 +8%, 치명 +5% | 왕의 검: 피해 +15% (♛2) |
| 군단 | 유닛 체력 +15%, 소환 비용 -10%, 유닛 피해 +15%·최대 유닛 +3 | 거인의 맹약: 유닛 **거인** 해금 (♛3) |
| 마나 | 최대 마나 +20, 마나 구슬 +20%, 최대 마나 +30 | 마력 샘: 마나 +50, 구슬 +25% (♛2) |
| 보물 | 동전·골드 +15%, 상점 -10%, 동전·골드 +15% | 황금 손: 동전·골드 +30%, 정수 +20% (♛2) |
| 생존 | 체력 +1, 대시 쿨 -15%, 체력 +2 | 두 번째 심장: 판마다 한 번 즉시 부활 (♛3) |

| 속성 | 액티브 1 | 패시브 | 액티브 2 |
|---|---|---|---|
| 불 | 화염구 | 불씨 (화상 적 처치 시 폭발) | 메테오 |
| 물 | 물결 | 치유의 물 (클리어 시 체력 +1) | 소용돌이 |
| 전기 | 낙뢰 | 정전기 (대시 후 공격이 연쇄 번개) | 뇌우 |
| 얼음 | 얼음 가시 | 서리 갑옷 (피격 시 주변 둔화) | 블리자드 랜스 |
| 바람 | 돌풍 | 순풍 (대시 쿨 -30%, 이속 +8%) | 토네이도 |
| 독 | 독구름 | 맹독 (독 중첩 +2) | 역병 |

### 스킨 (옷장)
- 로비의 **옷장**에서 E를 누르면 스킨을 사고 입을 수 있습니다. 능력치는 그대로입니다.
- 팀 색은 발밑 고리와 이름 색으로 보입니다: **1P 빨강 · 2P 초록 · 3P 파랑 · 4P 노랑** (군단 유닛도 주인 색 고리)
- **스킨은 캐릭터마다 따로** 있습니다 (위쪽 탭으로 캐릭터를 고름). 그 캐릭터를 산 뒤에 스킨을 살 수 있고, 캐릭터마다 입은 스킨을 따로 기억합니다.

| 캐릭터 | 색 스킨 (정수로 구매) | 장비 스킨 (모습이 바뀜, 🗺 모험 보물로만) |
|---|---|---|
| 기사 | 왕실 근위대 ◆80 · 황금 기사 ◆200 | 다크나이트 🗺 |
| 레인저 | 숲지기 ◆80 · 서리 사냥꾼 ◆120 | 정찰대장 🗺 |
| 마법사 | 잿불 술사 ◆100 · 유령 마도사 ◆180 | 대마법사 🗺 |
| 광전사 | 피의 투사 ◆100 · 북방 전사 ◆150 | 거인 혈통 🗺 |
| 도적 | 밤그림자 ◆100 · 황금 도둑 ◆200 | 사무라이 🗺 |
| 연금술사 | 독안개 ◆100 · 유령 조제사 ◆150 | 성스러운 조제사 🗺 |

- 색 스킨은 캐릭터의 **옷(망토·깃털·겉옷) 색**을 바꿉니다. 기본 스킨은 무료.
- 예전 공용 스킨(왕실·황금·대마법사 등)을 샀던 저장은 처음 켤 때 **그 값만큼 정수로 돌려받습니다.**
- 캐릭터마다 모습이 다릅니다: 기사(투구·체크 겉옷·방패), 레인저(두건·화살통), 마법사(챙 넓은 모자·로브), 광전사(뿔 투구·털옷), 도적(검은 두건·입가리개), 연금술사(고글·앞치마). 군단 유닛도 각자 모습이 있습니다.

### 계정 · 저장 코드
- 로그인은 **구글 로그인**과 **게스트** 두 가지입니다. 게스트는 이 브라우저에만 저장되고, 나중에 구글로 로그인하면 게스트 진행이 그대로 옮겨 갑니다.
- **다른 기기로 옮기기:** 같은 화면에서 **저장 코드**를 만들어 복사하고, 다른 기기에서 붙여 넣어 불러옵니다.
- 예전에 만든 아이디·비밀번호 계정은 그대로 쓸 수 있지만 새로 만들 수는 없습니다. 구글로 로그인하면 그 진행을 옮길 수 있어요.

### 무기와 진화 (diep.io 탱크처럼)
진화한 무기는 **완전히 별개의 무기**이고, 능력치가 더 강해집니다. 무기 계열(총·활·검·창·해머)마다 우클릭 스킬·패시브·궁극기를 공유합니다.

| 계열 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 총 | 권총 | 쌍권총 / 기관총 / 소총 / 샷건 | 삼연발총 / 미니건 / 저격총 / 전투 샷건 |
| 활 | 활 | 장궁 / 쇠뇌 / 연사궁 | 천궁 / 연발 쇠뇌 / 폭풍궁 |
| 검 | 검 | 대검 / 쌍검 | 참마도 / 칼날폭풍 |
| 창 | 창 | 할버드 / 랜스 | 삼지창 / 드래곤 랜스 |
| 해머 | 해머 | 워해머 / 지진 망치 | 거인의 망치 / 대지 분쇄기 |

(2단계 → 3단계는 바로 오른쪽 무기로: 쌍권총→삼연발총, 기관총→미니건, 소총→저격총, 샷건→전투 샷건 …)

- **진화:** 모험 모드에서 스테이지를 넘어갈 때, 들고 있는 무기의 다음 단계 중 하나를 고를 수 있습니다 (안 해도 됨). 속성은 그대로 유지됩니다.
- **모든 무기를 게임 중에 얻을 수 있습니다:** 1·2·3단계, 속성 있음/없음 모두 상자와 상점에서 나옵니다. 월드가 높을수록 높은 단계가 잘 나옵니다.
- **무기를 줍기 전**에 가까이 가면 능력치(피해, 발 수, 초당 공격, 치명, 명중, 사거리, 마나, 속성)가 말풍선으로 보입니다.
- **무기 이름 색 = 무기 속성 색**입니다 (속성 없으면 흰색).
- **무기 칸 2개** (스테이지 보상 '무기 벨트'로 3칸). 칸이 꽉 차면 들고 있는 무기를 내려놓고 바꿉니다.

| 계열 | 우클릭 스킬 | 패시브 | Q 궁극기 (충전 방식) |
|---|---|---|---|
| 검 | 돌진 베기 (6초) | 반격 자세: 총알을 막으면 다음 공격 +1 | 검기 폭풍 (적중 30회) |
| 창 | 투창 → 다시 누르면 회수 (7초) | 창끝 일격: 사거리 끝 +50% | 천 개의 창 (준 피해 40) |
| 해머 | 지면 강타 + 기절 (9초) | 강철 몸: 최대 체력 +2 | 대지 분쇄 (주고받은 피해) |
| 활 | 백스텝 사격 (5초) | 약점 포착: 같은 적 연속 적중 시 +1씩 | 화살비 (전투 30초) |
| 총 | 수류탄 (8초) | 연발 가속: 계속 쏘면 연사 +40%까지 | 난사 (처치 15회) |

- **스킬 쿨타임은 전투 중에만 찹니다** (모험: 문이 잠긴 방 안, 캠프: 적이 있을 때). 화살비처럼 시간으로 차는 궁극기도 같습니다. 쿨타임이 멈춰 있으면 숫자 옆에 ⏸가 보입니다.
- **샷건·쌍총열:** 한 번에 나가는 총알 묶음은 피해는 한 발씩 들어가지만, 빙결·화상 같은 **속성 효과는 적 하나당 한 번만** 들어갑니다. 얼었다 풀린 적은 1.5초 동안 다시 얼지 않습니다 (무한 빙결 방지).
- 권총은 느리게(초당 2.5회), 빠른 연사가 필요하면 기관총·미니건으로 진화하세요.

### 전투 수치
무기마다 **피해 · 공격 속도 · 명중률 · 치명타율 · 마나 소모**가 있고, 화면 오른쪽 아래에 지금 무기의 실제 수치가 표시됩니다.
적에게 준 피해는 숫자로 뜹니다. 치명타는 노란색이고, 지속 피해는 회색입니다. 설정에서 끌 수 있습니다.
샷건 계열은 거리 비례 피해(50px 이내 150% → 멀수록 50%), 저격총·쇠뇌·샷건은 공격 속도 증강을 받아도 최소 간격보다 빨라지지 않습니다.

### 마나 · 동전
- **마나는 저절로 차지 않습니다.** 적을 잡으면 떨어지는 **파란 구슬**을 주워서 채웁니다 (로비에서는 무한).
- 1단계 무기와 근접 무기, 궁극기는 마나를 쓰지 않습니다. 2·3단계 원거리 무기는 한 발마다 마나를 씁니다.
- **무기 스킬**은 15, **장착 스킬**은 쿨타임 × 2.5를 씁니다.
- 마나가 모자라면 쏠 수 없으니, 마나 없는 무기를 하나 들고 다니면 좋습니다.
- **동전(●)**: 모험 모드에서 적과 상자가 떨어뜨리는 노란 구슬입니다. 상점에서 씁니다.
- 경험치(초록)·마나(파랑)·동전(노랑) 구슬은 모두 **플레이어마다 따로** 생깁니다. 1P가 먹어도 2P 몫은 남아 있습니다.

### 경험치와 레벨 (그 판에서만 유지)
- 레벨이 오르면 **증강 카드 3장 중 1장**을 클릭해서 고릅니다. 한 번에 여러 레벨이 오르면 카드가 차례로 나옵니다.
- **증강은 한 판에 5종류까지** 가질 수 있습니다 (속성 카드도 1종류). 5종류를 채우면 이미 가진 증강의 레벨업 카드만 나옵니다.
- 증강 수치는 작게, 몬스터는 스테이지마다 강해집니다 (`src/data.js`의 `BUFFS`, `enemyScale`, `xpToNext`).

### 모험 모드 (랜덤 던전)
- 스테이지마다 **방과 복도가 랜덤으로 생성**됩니다. 시작 방 → 전투 방들 → 포털 방, 그리고 **상점방**과 **상자방**이 하나씩 있습니다.
  - **상점방:** 무기 2개(속성 있으면 더 비쌈), 체력 물약, 마나 물약 또는 증강 두루마리. 먼저 산 사람이 가져갑니다.
  - **상자방:** 큰 상자 하나 (2단계 이상 무기 + 동전·마나).
  - 전투 방을 클리어하면 가끔(20%) 상자가 나오고, 보스방은 반드시 나옵니다.
- 전투 방에 들어가면 **문이 잠기고**, 다른 팀원은 그 방으로 불려 옵니다. 적을 다 잡으면 문이 열립니다.
- 방에는 웨이브가 1~3번 있습니다. 한 웨이브를 다 잡으면 **다음 몬스터가 나올 자리에 빨간 조준경**이 약 1.6초 동안 보이고(점점 좁아지다 직전에 깜빡임), 그 자리에서 몬스터가 나옵니다.
- 쓰러진 팀원은 방을 클리어하면 체력 절반으로 부활합니다.

#### 🗺 모험 보물 (모험 모드에서만 얻는 해금)
모험 모드는 성 지키기 군단·성 지키기 강화·장비 스킨을 얻으려면 **꼭 해야 하는 모드**입니다.
- **보스를 잡으면 모든 플레이어가 보물 1개씩**, 일반 상자를 열면 가끔(15%) 모두 1개씩 받습니다. 아직 없는 것 중에서 무작위로 나오고, 다 모았으면 대신 ◆80.
- 판이 끝나면 저장되고 하나씩 크게 보여 줍니다.

| 보물 | 효과 |
|---|---|
| 스카웃·마법사·성직자 입대 문서 | 성 지키기 군단에 그 유닛 합류 (병영에서 정수로 해금하던 것 → 보물로만) |
| 강철 울타리 설계도 | 내가 지은 울타리 체력 10 → 20 |

- 오른쪽 위 **미니맵:**
  - 회색 ? 칸: 길은 알지만 아직 안 가 본 방
  - 다음 방의 종류는 **복도를 절반 넘게 건너야** 보입니다: ★ 보스, $ 상점, ▣ 상자, 보라 네모 포털
  - 빨강은 전투 중, 초록은 클리어한 방입니다.
- 포털 위에 **살아 있는 팀원이 모두 모여야** 다음 스테이지로 출발합니다.
- **스테이지 보상:** 다음 스테이지로 넘어갈 때 고르는 강력한 효과로, **종류마다 한 판에 1번만** 얻을 수 있습니다.

  - 남은 보상이 3개보다 적으면 **휴식**(체력 완전 회복, 반복 가능)으로 채웁니다.

### 성 지키기 (베이스캠프 모드) — 성키우기 + 디펜스
넓은 들판(72x52칸) 한가운데 **성(탑)**을 **10분 동안 지킵니다.** 모험 모드는 소울나이트 방식 그대로입니다.

- 화면 위에 **골드 · 성 체력 · 군단 · 킬**이 보입니다. **성이 무너지면 패배**합니다.
- 적은 가까운(160px) 플레이어·유닛이 없으면 **성으로 몰려갑니다.** 궁수·마법사 적은 성을 쏘기도 하니 먼저 잡으세요.
- **성:** 사거리 안의 적에게 자동으로 화살을 쏩니다. **T**로 골드를 써서 강화(최대 체력 +30, 화살 강화, 5레벨부터 2발, 최대 8레벨).
- **군단 소환 (4·5·6·7 키):** 팀 공용 골드로 병영에서 고른 유닛을 성 옆에 부릅니다. 유닛은 성 근처의 적과 알아서 싸우고, 할 일이 없으면 성 주위를 지킵니다. 한 사람당 최대 12명(스킬 트리로 늘림).
- **골드:** 적을 잡으면 팀 골드가 쌓입니다. 소환·성 강화·울타리·터렛에 씁니다.

1. **준비 15초:** 캠프(점선 원) 안에 울타리와 터렛을 짓습니다. 모두 G를 누르면 바로 시작합니다.
2. **물량:** 적이 화면 밖에서 끊임없이 몰려옵니다. 시간이 갈수록 더 자주, 더 많이, 더 다양하게 나옵니다.
3. **정예 (2:30 · 5:00 · 7:30):** 커다란 정예 오크가 주변을 내려찍습니다 (빨간 경고 원). 잡으면 상자가 나옵니다.
4. **보스 (10:00):** 보스를 잡으면 **성을 지켜냈다!** (왕관 +2). 쓰러지면 20초 뒤 부활합니다.
- **레벨업 증강은 없습니다.** 대신 군단·성 강화·건물로 강해집니다. 적은 경험치 대신 골드·마나를 떨어뜨립니다.
- 시작 체력 +3, 캠프 안에서는 5초마다 체력 +1. 적이 가끔 **고기**(체력 +1)를 떨어뜨립니다.
- **상자 = 전리품(✪):** 2분마다 캠프 옆에, 정예를 잡으면 그 자리에 상자가 나옵니다. 열면 **모든 플레이어가** 전리품을 받습니다 (상자 ✪4, 정예 상자 ✪6, 승리 ✪10). 전리품은 판이 끝나면 저장돼서 로비에서 씁니다.

| 조합 | 효과 |
|---|---|
| 무기 속성 = 캐릭터 속성 | **공명:** 피해 ×1.2, 속성 레벨 +1, 궁극기 충전 +25% |
| 무기 속성 ≠ 캐릭터 속성 | **결합:** 3번째 공격마다 캐릭터 속성도 함께 들어가서 원소 반응을 혼자서도 일으킴 |
| 무기에 속성 없음 | 캐릭터 속성으로 공격 |

| 속성 | 효과 |
|---|---|
| 🔥 불 | 화상 (0.5초마다 피해 1) |
| 💧 물 | 젖음 (이동속도 -20%) |
| ⚡ 전기 | 주변 적에게 연쇄 번개 (레벨만큼 튐) |
| ❄️ 얼음 | 둔화 (-40%), 3번 맞히면 빙결 |
| 🌪 바람 | 넉백, 탄속 +30%, 상태이상을 주변 적에게 확산 |
| ☠️ 독 | 중독 (1초마다 중첩 수만큼 피해) |

| 반응 | 조건 | 효과 |
|---|---|---|
| 감전 | 젖은 적 + 전기 | 주변의 젖은 적 모두에게 피해 + 기절 |
| 빙결 | 젖은 적 + 얼음 | 즉시 얼려서 멈춤 |
| 녹임 | 얼음/둔화 + 불, 화상 + 얼음 | 큰 추가 피해 |
| 증발 | 젖음 + 불, 화상 + 물 | 추가 피해 |
| 폭발 | 중독 + 불, 화상 + 독 | 주변 범위 피해 |
| 확산 | 상태이상 걸린 적 + 바람 | 주변 적에게 같은 상태이상 |

화상이나 독 같은 지속 피해, 반응 피해로 적이 쓰러지면 마지막으로 때린 사람이 점수를 받습니다.

- **멀티플레이:** 다른 사람의 게임은 계속 진행됩니다. 내 캐릭터는 그 자리에 멈추고, 동료 화면에는 이름 옆에 ⏸가 표시됩니다.

증강마다 최대 레벨이 있고, 같은 증강을 다시 고르면 레벨이 오릅니다.

### 길드 (온라인)
로비의 **길드 회관**(또는 시작 메뉴의 🛡 길드)에서 씁니다. 길드는 **Firebase**(구글의 무료 서버)에 저장되어, 어느 기기에서든 같은 길드를 볼 수 있습니다.

- **길드 찾기·가입:** 이름으로 검색해서 가입 (최대 20명)
- **길드 만들기:** ◆50, 이름(2~12글자)·색·소개
- **기부:** 정수를 기부하면 길드 경험치가 오르고 레벨업 (최대 20레벨)
- **길드 보너스 (길드원 모두):** 레벨마다 정수 +3%, 피해 +1%, 성 체력 +2, 소환 비용 -1%
- **같은 방 시너지:** 멀티플레이에서 같은 길드원 1명마다 피해 +5%. 이름 위에 [길드명]이 보입니다.
- **채팅**(5초마다 새 메시지 확인), **랭킹**(길드 경험치 순), 길드장은 길드원을 내보낼 수 있고, 길드장이 나가면 기여도 1등에게 넘어갑니다. 마지막 사람이 나가면 길드가 없어집니다.

#### 길드 서버 설정 (처음 한 번)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 을 사용 설정합니다.
3. **빌드 → Realtime Database → 데이터베이스 만들기** (위치는 아무거나, '잠금 모드'로 시작) → **규칙** 탭에 아래를 붙여 넣고 **게시**합니다.
4. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(</>) 앱 추가** → 나오는 `apiKey`와 `databaseURL`을 복사합니다.
5. `src/config.js`의 두 칸에 붙여 넣고 커밋하면 모두에게 적용됩니다. (또는 게임의 길드 회관 → **서버 설정**에 붙여 넣으면 그 브라우저에만 적용)

`apiKey`는 공개돼도 괜찮은 값이고, 안전은 아래 규칙이 지킵니다.

```json
{
  "rules": {
    "users": {
      ".read": "auth != null",
      "$uid": { ".write": "auth != null && auth.uid === $uid" }
    },
    "saves": {
      "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" }
    },
    "guildIndex": { ".read": "auth != null", "$gid": { ".write": "auth != null" } },
    "guildNames": { "$name": { ".read": "auth != null", ".write": "auth != null" } },
    "guilds": {
      "$gid": {
        ".read": "auth != null",
        ".write": "auth != null && (!data.exists() || data.child('members').child(auth.uid).exists() || newData.child('members').child(auth.uid).exists())",
        "members": {
          "$uid": { ".write": "auth != null && (auth.uid === $uid || root.child('guilds').child($gid).child('leader').val() === auth.uid)" }
        }
      }
    },
    "guildChat": {
      "$gid": {
        ".read": "auth != null && root.child('users').child(auth.uid).child('guild').val() === $gid",
        ".write": "auth != null && root.child('users').child(auth.uid).child('guild').val() === $gid",
        "$msg": { ".validate": "newData.child('text').isString() && newData.child('text').val().length <= 120" }
      }

}
```

#### 구글 계정 연동 (클라우드 저장)
시작 메뉴의 **구글 로그인 → Google 계정으로 로그인**. 로그인하면 정수·스킬 트리·스킨·군단·전리품이 서버(`saves/{uid}`, 본인만 읽고 쓰기)에 자동 저장되어, 태블릿·PC 어디서든 같은 구글 계정으로 이어 할 수 있습니다.
- 처음 구글로 로그인하면 **지금 하던 진행과 길드가 그대로** 구글 계정으로 옮겨 갑니다 (익명 로그인에 구글을 이어 붙임).
- 이미 다른 기기에서 쓰던 구글 계정이면 **더 최근 저장**(기기 ↔ 클라우드)을 씁니다. 계정 화면의 **지금 동기화**로 언제든 맞출 수 있습니다.
- 저장할 때마다 2.5초 모았다가 올리고, 탭을 닫거나 숨길 때도 올립니다.

처음 한 번 Firebase 콘솔에서:
1. **Authentication → 로그인 방법 → 새 제공업체 추가 → Google** → 사용 설정, 지원 이메일 선택 → 저장
2. **Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `kimjaeyun091018-spec.github.io`
3. **Realtime Database → 규칙**을 위 규칙으로 다시 게시 (`saves` 부분이 새로 생겼어요)

로그인 창 주소(authDomain)는 `databaseURL`에서 자동으로 만듭니다 (`<프로젝트>.firebaseapp.com`). 다르면 `src/config.js`에 `authDomain`을 적으세요. 팝업이 막히면 브라우저에서 이 사이트의 팝업을 허용하세요.

⚠️ 정수·게임 결과는 각자 브라우저에 저장되기 때문에, 마음먹고 조작하면 기부 수치를 속일 수 있습니다. 친구끼리 쓰는 용도로 생각해 주세요. Firebase 무료 요금제(Spark)로 충분합니다.

## 멀티플레이 방식

```
 [방장 브라우저] ── 게임 계산(game.js) ──▶ 상태 전송 (초당 20회)
      ▲                                        │
      │ 입력 전송 (초당 30회)                   ▼
 [참가자 브라우저] ◀──── 받은 상태를 부드럽게 보간해서 그림
```

- **PeerJS(WebRTC P2P)**를 사용합니다. 방장의 브라우저가 서버 역할을 하므로 **서버를 따로 운영할 필요가 없습니다.**
- 서로를 처음 찾아 연결할 때만 PeerJS의 무료 공개 서버를 이용합니다.
- 방장이 **방 만들기**를 누르면 5자리 방 코드가 생깁니다. 친구는 그 코드를 입력하고 **참가**를 누르면 됩니다.
- 방장이 나가면 방도 함께 사라집니다.
- 일부 학교나 회사 네트워크에서는 P2P 연결이 막힐 수 있습니다. 그럴 때는 나중에 TURN 서버를 추가하거나 Node.js 서버 방식으로 바꿔야 합니다.
