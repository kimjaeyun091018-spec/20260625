# 던전 슈터 (가제)

Soul Knight 스타일의 탑다운 로그라이크 슈팅 게임입니다. **PC 키보드와 마우스**로 플레이하고, **최대 4명 협동 멀티플레이**를 지원합니다.
설치 없이 브라우저에서 바로 실행되므로 태블릿에서도 개발하고 테스트할 수 있습니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | WASD / 방향키 |
| 조준 | 마우스 |
| 공격 | 왼쪽 클릭 (누르고 있으면 연사) |
| 대시 (잠깐 무적) | Space / Shift |
| 울타리 짓기 (베이스캠프, 마우스 위치) | E |
| 터렛 짓기 (마우스 위치) | R |
| 건물 철거 (반값 환불) | F |
| 증강 / 스테이지 보상 선택 | 1 / 2 / 3 또는 카드 클릭 |
| 준비 완료 (베이스캠프, 모두 준비하면 바로 다음 웨이브) | G |
| 일시정지 (계속하기 / 메뉴로 나가기) | Esc |

태블릿에서 키보드 없이 테스트할 때는 화면을 터치하거나 펜으로 누르면 그 방향으로 조준하고 사격합니다. 강화 카드도 터치로 고를 수 있지만, 이동은 키보드가 있어야 합니다.

## 게임 흐름

**시작 메뉴 → 로비 → (베이스캠프 / 모험) → 로비**

### 로비
- 왼쪽에 **1P~4P 슬롯**이 있고, 멀티로 들어온 사람이 바로 보입니다.
- **무기 선택:** 검 · 창 · 해머 · 활 · 총
  - 2인 플레이: 같은 무기를 고를 수 없습니다.
  - 3~4인 플레이: 한 무기를 최대 2명까지 고를 수 있습니다.
- **모드 선택과 게임 시작**은 방장만 할 수 있습니다.
- 아래쪽 **토템 칸**은 자리만 만들어 두었습니다 (3단계에서 추가 예정).

### 무기 (기본 공격)

| 무기 | 종류 | 특징 |
|---|---|---|
| 🗡️ 검 | 근접 | 넓게 베기, 적 총알을 베어서 막음 |
| 🔱 창 | 근접 | 긴 사거리 찌르기, 일직선의 적 관통 |
| 🔨 해머 | 근접 | 느리지만 강한 범위 공격, 큰 넉백 |
| 🏹 활 | 원거리 | 강하고 관통하는 화살 |
| 🔫 총 | 원거리 | 빠른 연사 |

근접 무기에는 멀티샷·관통·도탄 증강이 나오지 않고, 대신 **긴 팔(근접 범위 +20%)**이 나옵니다.

### 경험치와 레벨 (그 판에서만 유지)
- 적을 잡으면 초록색 **경험치 구슬**이 떨어집니다.
- 구슬은 **플레이어마다 따로** 생깁니다. 1P가 먹어도 2P 화면에는 그대로 남아 있어서, 2P도 따로 주울 수 있습니다.
- 레벨이 오르면 **증강 카드 3장 중 1장**을 고릅니다. 한 번에 여러 레벨이 오르면 카드가 차례로 나옵니다.

### 모험 모드 (랜덤 던전)
- 스테이지마다 **방과 복도가 랜덤으로 생성**됩니다. 시작 방 → 전투 방들 → 포털 방 순서입니다.
- 전투 방에 들어가면 **문이 잠기고**, 다른 팀원은 그 방으로 불려 옵니다. 적을 다 잡으면 문이 열립니다.
- 쓰러진 팀원은 방을 클리어하면 체력 절반으로 부활합니다.
- 오른쪽 아래 **미니맵** 색깔: 회색은 발견한 방, 빨강은 전투 중, 초록은 클리어한 방입니다.
- 포털 위에 **살아 있는 팀원이 모두 모여야** 다음 스테이지로 출발합니다.
- **스테이지 보상:** 다음 스테이지로 넘어갈 때 고르는 강력한 효과로, 레벨업 증강과는 별개입니다.
  - 속성 각성, 거인의 심장, 전사의 혼, 질풍, 배움의 서, 철의 의지
- 스테이지는 `1-1 → … → 1-5 → 2-1 → … → 3-5` 순서이고, 3-5를 깨면 클리어입니다. 갈수록 방이 많아지고 적이 강해집니다.

### 베이스캠프 모드
1. **준비 시간:** 맵 중앙의 **베이스캠프**(점선 원 안)에 울타리와 터렛을 짓습니다. 캠프 안에 있으면 체력이 천천히 회복됩니다.
2. **웨이브:** 적이 캠프 바깥에서 몰려옵니다. 적을 잡으면 **팀 공용 골드**와 경험치를 얻습니다.
3. 쓰러진 동료는 다음 웨이브가 시작될 때 부활합니다.

전원이 쓰러지면 결과를 보여 준 뒤 로비로 돌아갑니다.

### 베이스캠프 건물

| 건물 | 가격 | 설명 |
|---|---|---|
| 울타리 | 5 | 적의 이동과 적 총알을 막습니다. 아군과 아군 총알은 통과합니다. 근접 적이 부술 수 있습니다. |
| 터렛 | 30 | 사거리 안의 가장 가까운 적을 자동으로 쏩니다. |

### 속성 (원소)

레벨업 증강 카드에 **속성 카드**도 섞여 나옵니다. 아직 속성이 없으면 속성 카드가 최소 1장 나옵니다.
한 사람은 **한 속성만** 가질 수 있습니다. 같은 속성을 다시 고르면 레벨업(최대 3)하고, 다른 속성을 고르면 그 속성으로 바뀝니다.
멀티플레이에서 **동료와 서로 다른 속성**을 고르면 아래 반응을 일으킬 수 있습니다.

| 속성 | 효과 |
|---|---|
| 🔥 불 | 화상 (0.5초마다 피해 1) |
| 💧 물 | 젖음 (이동속도 -20%) |
| ⚡ 전기 | 주변 적에게 연쇄 번개 (레벨만큼 튐) |
| ❄️ 얼음 | 둔화 (-40%), 3번 맞히면 빙결 |
| 🌪 바람 | 넉백, 탄속 +30%, 상태이상을 주변 적에게 확산 |
| ☠️ 독 | 중독 (1초마다 중첩 수만큼 피해) |

| 반응 | 조건 | 효과 |
|---|---|---|
| 감전 | 젖은 적 + 전기 | 주변의 젖은 적 모두에게 피해 + 기절 |
| 빙결 | 젖은 적 + 얼음 | 즉시 얼려서 멈춤 |
| 녹임 | 얼음/둔화 + 불, 화상 + 얼음 | 큰 추가 피해 |
| 증발 | 젖음 + 불, 화상 + 물 | 추가 피해 |
| 폭발 | 중독 + 불, 화상 + 독 | 주변 범위 피해 |
| 확산 | 상태이상 걸린 적 + 바람 | 주변 적에게 같은 상태이상 |

화상이나 독 같은 지속 피해, 반응 피해로 적이 쓰러지면 마지막으로 때린 사람이 점수를 받습니다.

### 일시정지

- **혼자 하기:** Esc를 누르면 게임이 완전히 멈춥니다. 다른 창으로 전환해도 자동으로 멈춥니다.
- **멀티플레이:** 다른 사람의 게임은 계속 진행됩니다. 내 캐릭터는 그 자리에 멈추고, 동료 화면에는 이름 옆에 ⏸가 표시됩니다.

### 증강 목록

공격력 강화, 빠른 손(공속), 멀티샷, 날쌘 발(이속), 튼튼한 몸(최대 체력), 관통탄, 도탄(벽 튕김), 그림자 대시(쿨타임), 흡혈, 긴 팔(근접 범위).
증강마다 최대 레벨이 있고, 같은 증강을 다시 고르면 레벨이 오릅니다.

## 실행하기

### 1. GitHub Pages로 배포하기 (태블릿 추천)
1. 저장소에서 **Settings → Pages**로 이동합니다.
2. Source는 **Deploy from a branch**, 브랜치는 `feature/roguelike-shooter-pc` / `(root)`를 선택합니다.
3. 1~2분 정도 기다리면 `https://kimjaeyun091018-spec.github.io/20260625/` 주소로 접속할 수 있습니다.
4. 친구에게 이 주소를 보내 주면 각자 브라우저에서 바로 참가할 수 있습니다.

> GitHub Pages는 한 번에 브랜치 하나만 배포할 수 있습니다. 다른 브랜치를 배포하고 있었다면 배포 대상이 이 브랜치로 바뀝니다.

### 2. PC에서 로컬로 실행하기
`index.html`을 파일로 바로 열면 ES 모듈이 막히기 때문에 간단한 서버가 필요합니다.
```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 멀티플레이 방식

```
 [방장 브라우저] ── 게임 계산(game.js) ──▶ 상태 전송 (초당 20회)
      ▲                                        │
      │ 입력 전송 (초당 30회)                   ▼
 [참가자 브라우저] ◀──── 받은 상태를 부드럽게 보간해서 그림
```

- **PeerJS(WebRTC P2P)**를 사용합니다. 방장의 브라우저가 서버 역할을 하므로 **서버를 따로 운영할 필요가 없습니다.**
- 서로를 처음 찾아 연결할 때만 PeerJS의 무료 공개 서버를 이용합니다.
- 방장이 **방 만들기**를 누르면 5자리 방 코드가 생깁니다. 친구는 그 코드를 입력하고 **참가**를 누르면 됩니다.
- 방장이 나가면 방도 함께 사라집니다.
- 일부 학교나 회사 네트워크에서는 P2P 연결이 막힐 수 있습니다. 그럴 때는 나중에 TURN 서버를 추가하거나 Node.js 서버 방식으로 바꿔야 합니다.

## 파일 구조

```
index.html     시작 메뉴, 로비, 스테이지 보상 화면, 일시정지
style.css      화면 스타일
src/data.js    수치 모음: 무기, 적, 증강, 속성, 스테이지 보상 (밸런스 조절은 여기)
src/maps.js    베이스캠프 맵과 랜덤 던전 생성
src/game.js    게임 규칙과 시뮬레이션 (로비, 두 모드, 전투, 경험치). 화면·네트워크 코드 없음
src/render.js  캔버스 그리기 (카메라, 미니맵, HUD)
src/net.js     PeerJS로 방 만들기와 참가하기
src/main.js    입력, 게임 루프, 로비·보상 화면, 메뉴
```

수치는 `src/data.js`, 규칙은 `src/game.js`에서 고치면 됩니다. 게임 계산은 방장 브라우저에서만 하므로 참가자 쪽 코드는 바꾸지 않아도 됩니다.

## 개발 로드맵

### 2단계: 무기 심화
- [ ] 무기마다 **기본 스킬 · 패시브 스킬 · 특수 스킬(궁극기)**
  - 궁극기 충전 방식: 스택 쌓기 / 충전 / 시간 대기
- [ ] 무기 **2개 보유**(강화하면 3개), 무기 교체 쿨타임
  - 충전된 스킬과 궁극기는 무기를 바꿔도 보관
  - 들고 있지 않은 무기의 쿨타임 스킬도 자동 충전
- [ ] 무기 **전직(업그레이드)** 트리: 예) 활 → 쇠뇌 / 강화 활
- [ ] 무기마다 속성 부여, 캐릭터 속성과 같으면 추가 효과 (강화 가능)
- [ ] 공격·스킬 **키 설정 변경**

### 3단계: 영구 성장과 로비
- [ ] **캐릭터** 선택: 캐릭터마다 고유 속성과 스킬
- [ ] 로비 **영구 스탯 칸 4개**: 처음 저장할 때는 무료, 칸 구매나 칸 초기화는 비용 지불
- [ ] **토템 칸**
- [ ] 재화 (게임 중 획득)
- [ ] **하드코어 모드:** 일반 모드를 클리어하면 해금. 맵이 훨씬 넓고 몬스터가 강하며, 멀티에서 팀원 부활 불가
- [ ] 멀티 이어하기: 같이 하던 플레이어 전원이 다시 접속해야 진행
