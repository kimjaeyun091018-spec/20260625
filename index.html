지브리풍 · AI 화풍 설정

캔버스 필터만으로는 진짜 AI 화풍 변환(지브리풍 등)을 만들 수 없어요. 이 사이트는 정적 페이지라 API 키를 서버에 숨길 수 없으니, 본인만 쓰는 브라우저에서 개인 API 키를 임시로 넣어 사용하는 방식이에요. 키는 이 브라우저의 로컬 저장소에만 저장되고, 깃허브 저장소나 다른 사람에게 전송되지 않아요.

엔드포인트 규격: POST로 { "image": "data:image/jpeg;base64,..." } 전송 → { "image": "data:image/jpeg;base64,..." } 형식으로 변환된 이미지를 응답해야 해요. README의 "AI 화풍 연동" 절에 Replicate/fal.ai 예시가 있어요.
