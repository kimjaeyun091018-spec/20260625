AI 화풍 서버 설정

"피카소 스타일 (AI)" 화풍을 쓰려면 이미지 변환 서버 주소가 필요해요. Colab에서 colab-ai-server.py를 실행하면 나오는 주소를 아래에 붙여넣어 주세요. Colab을 다시 시작할 때마다 주소가 바뀌니, 그때마다 갱신해야 해요. 입력한 값은 이 브라우저에만 저장되고 다른 곳으로 전송되지 않아요.

엔드포인트 규격: POST로 { "image": "data:image/jpeg;base64,...", "style": "picasso" } 전송 → { "image": "data:image/jpeg;base64,..." } 형식으로 변환된 이미지를 응답해야 해요. API 키 칸은 Colab 서버를 쓸 때는 비워두면 돼요.
